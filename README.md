# Puskar Khadka — Portfolio

Personal portfolio website built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

## Customization

- `data/experience.ts` — update job history
- `data/projects.ts` — update projects
- `data/skills.ts` — update skill categories
- `components/contact.tsx` — update social links and email
- `public/resume.pdf` — add your resume PDF
